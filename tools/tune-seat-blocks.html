Seat-block placement tuner

Drag a block to place it. Position is stored in projected map units (a circuit's block lives in national.svg's space, a district's in its circuit-local file) so it stays glued to its court; size is in CSS px, so squares stay the same on-screen size in every view. Export writes data/seat_blocks.csv — placement is a data-only change: drop the CSV in, re-run build_assets.py, done. No code edits.

Untouched courts are omitted from the CSV on purpose — they fall back to the centre of their largest shape part, which keeps re-tuning after a geometry re-export cheap. The Federal Circuit has no geometry at all, so it is always exported.
