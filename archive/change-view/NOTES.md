# Change view (archived 2026-09-10, issue #67)

## What it was

A third pane mode alongside Timeline and Majority, selected via a `[ Timeline | Majority | Change ]`
segmented control on every ordinary court pane (not Summary > SCOTUS, which never had it). It
rendered a party-stacked streamgraph: one "stream" per appointing president's term, showing that
term's currently-serving (active + senior) appointee headcount on the selected court, evaluated at
every appointment/departure event since 1969-01-20. Republican streams stacked above a zero line,
Democratic below; a draggable vertical time bar showed each president's headcount-at-that-date via
floating avatar icons. A `None|FedSoc|ACS`-style two-way switch (`Alternating`/`Fading`) picked
between two color-coding schemes for the streams.

Built session (aw); refined through several operator rounds (session ax and later). Removed by
explicit operator request, 2026-09-10 (issue #67), as part of a larger backlog — no specific reason
recorded beyond "remove it."

## What it depended on

- `data/appointments.json` and `data/president_photos.json` — **these data files are NOT
  archived/removed**. They're real, shared assets: `data/appointments.json` is the appointments
  beeswarm widget's (`embed/appointments-chart.js`) own primary data source, generated by
  `scripts/build_assets.py`. Only `court-tracker.js`'s own consumption of them
  (`S.appointmentsAll`/`S.presidentPhotos`, `ensureChangeData()`) was removed.
- `embed/presidencies.js` (the `PRESIDENCIES` array) — **also NOT removed**, for the same reason:
  `embed/appointments-chart.js` imports it too. Only `court-tracker.js`'s own
  `import { PRESIDENCIES } from "./presidencies.js"` was removed (it had no other use in that
  file).
- The day-number helpers `DAY_MS`/`dayNum`/`isoOfDayNum` (near the top of `court-tracker.js`) WERE
  removed along with this feature — confirmed via a full-file grep that every call site was inside
  the Change-view block itself. If reintroducing, check that they haven't since been reintroduced
  for some unrelated reason (a fresh grep is cheap) before restoring them, to avoid a duplicate
  definition.
- CSS custom properties `--ctt-band-rep`/`--ctt-band-dem` (used only by `.ctt-stream-band-rep`/
  `.ctt-stream-band-dem`) WERE removed from `.ctt-root`'s token block along with the CSS rules that
  used them — confirmed via grep that nothing else referenced them.
- `S.paneMode`'s `'change'` value, `S.streamColorScheme`, the `changeBtn`/`streamStage` DOM nodes
  and their branches in `renderPane`'s `setMode`, and the stale-render guard checking
  `S.paneMode !== "change"` were all part of the ordinary per-court pane wiring (`renderPane`,
  `embed/court-tracker.js`) — see the excerpt files below for the exact removed code.
